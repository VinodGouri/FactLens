# Data

## raw/
`News.csv` — downloaded from https://github.com/ApnaClassroom/Dataset/blob/main/News.csv
- 10,240 rows, 2 columns: `News` (short political statement / news title), `Fake` (boolean).
- The row count and class counts (5,752 `TRUE` / 4,488 `FALSE`) match the LIAR (PolitiFact) training split binarised as
  {true, mostly-true, half-true} vs {false, barely-true, pants-on-fire}. For example, row 0 is a claim PolitiFact rated *false*, and it has `Fake = FALSE`.
  So `Fake == TRUE` means the statement is **truthful**. The notebooks therefore use `label = 1 (Fake)` when `Fake == FALSE` and `label = 0 (Real)` when `Fake == TRUE`.
